| ThemeTokens | configuration | `src/web/theme/tokens.css` | The mock's dark and editorial-light tokens with the light-blue accent, status colours, the orange of "Interrupt", fixed terminal colours, shadows and focus ring | `specs/theme-tokens.md` |
| ThemeStore | frontend service | `src/web/theme/theme-store.ts` | Active theme of the page, started from the page mark, its `data-theme` mark on the root, and the toggle that saves it in `localStorage` | `specs/theme-store.md` |

| LookStore | frontend service | `src/web/theme/look-store.ts` | Active look of the page (current or Windows 11), started from the page mark, its `data-look` mark on the root, and the toggle that saves it in `localStorage` | `specs/look-store.md` |
| LookSwitch | UI component | `src/web/LookSwitch.tsx` | Top-bar icon button "Windows 11 look" that shows the active look and toggles it | `specs/look-switch.md` |

| ShortcutsButton | UI component | `src/web/ShortcutsButton.tsx` | Top-bar keyboard icon button "Keyboard Shortcuts" that opens and closes the shortcuts panel, above the dialog backdrop while the panel is open | `specs/shortcuts-button.md` |
| ShortcutsPanel | UI component | `src/web/ShortcutsPanel.tsx` | Dialog "Keyboard Shortcuts" that lists every row of the shortcut map by area, keys in keyboard badges | `specs/shortcuts-panel.md` |
| BundledFont | configuration | `src/web/fonts/roboto.css`, `src/web/fonts/roboto-flex-latin.woff2`, `src/web/fonts/roboto-mono-latin.woff2`, `src/web/fonts/OFL.txt` | Roboto Flex and Roboto Mono fonts shipped with the client, with their licence | `specs/bundled-font.md` |
| Dialog | UI component | `src/web/dialogs/Dialog.tsx` | Shared modal frame of the mock: header with "[Esc]", body, footer with "Cancel" and an optional primary action ("Close" alone without it), Enter, Esc, focus trap | `specs/dialog.md` |

| AreaState | UI component | `src/web/feedback/AreaState.tsx` | Empty, loading or error block that fills an area, in full or compact size | `specs/area-state.md` |
| ProgressIndicator | UI component | `src/web/feedback/ProgressIndicator.tsx` | Rotating indicator with a label for a loading area, and the Spinner of a busy button | `specs/progress-indicator.md` |
| ErrorMessage | UI component | `src/web/feedback/ErrorMessage.tsx` | Icon and text in rose, announced as an alert | `specs/error-message.md` |
| ShortcutMap | configuration | `src/web/shortcut-map.ts` | The one list of the client shortcuts, terminal keys included: key, modifiers, area, action text and command, and the lookup of a key event | `specs/shortcut-map.md` |
| useShortcutKeys | frontend hook | `src/web/shortcut-keys.ts` | Window `keydown` listener in the capture phase: runs the command of a map key, cancels and stops the event; does nothing while a dialog is open, except the panel key over the shortcuts panel | `specs/shortcut-keys.md` |
| ShortcutChannel | frontend service | `src/web/shortcut-channel.ts` | Sends a session command of a shortcut (stop, dismiss, resume, rename) to the mounted component that subscribed to it; no subscriber, no effect | `specs/shortcut-channel.md` |

| IconSet | UI component | `src/web/icons/Icons.tsx`, `src/web/icons/LICENSE` | Lucide icons, and the look and window-button glyphs drawn for the client, as local decorative SVG components, with the Lucide licence | `specs/icon-set.md` |
| planLimitsOf | backend function | `src/server/plan-limits-rule.ts` | Body of the Anthropic usage answer to the plan limits (label, whole percentage, reset time): the `limits` rows, else the fallback keys | `specs/plan-limits-rule.md` |
| readAccessToken | backend service | `src/server/claude-credentials-token.ts` | Gives `claudeAiOauth.accessToken` from `<claudeDir>/.credentials.json`, read-only; the only reader of that file (human exception to the credentials rule of module history) | `specs/credentials-token-reader.md` |
| PlanLimitsReader | backend service | `src/server/plan-limits-reader.ts` | One call to the Anthropic usage endpoint with the token: `ok` with the limits, `unavailable` (no token) or `error` | `specs/plan-limits-reader.md` |
| PlanUsageRoute | REST endpoint | `src/server/plan-usage-route.ts` | `GET /api/plan-usage`: the result of the reader, overlapping calls share one request, never the token | `specs/plan-usage-route.md` |
| remainingText, resetDateText, lastReadText | frontend function | `src/web/plan-usage/reset-time-format.ts` | Time remaining ("2h 15m", "3d 4h", "<1m"), reset date and time ("Mon 14 Nov, 18:30") and last read time | `specs/reset-time-format.md` |
| PlanUsageStore | frontend hook | `src/web/plan-usage/plan-usage-store.ts` | `usePlanUsage(open)`: loads the limits once on open, state `loading`, `ready` or `unavailable` | `specs/plan-usage-store.md` |
| PlanLimitRow | UI component | `src/web/plan-usage/PlanLimitRow.tsx` | One limit: label, percentage as a number and a progress bar with the usage level colours, "Resets in" time and date | `specs/plan-limit-row.md` |
| PlanUsagePopover | UI component | `src/web/plan-usage/PlanUsagePopover.tsx` | Non-modal panel "Plan Usage" under the top bar: loading, rows and "not available" | `specs/plan-usage-popover.md` |
| PlanUsageButton | UI component | `src/web/PlanUsageButton.tsx` | Top-bar gauge icon button "Plan Usage" that opens and closes the popover | `specs/plan-usage-button.md` |
| newerVersionOf | backend function | `src/server/version-rule.ts` | Release tag against the installed version as `MAJOR.MINOR.PATCH` (leading `v` ignored): the newer version, else `null` | `specs/version-rule.md` |
| checkLatestRelease | backend service | `src/server/release-check.ts` | One GET for the latest release, no credentials, 10 s limit: `newer` with both versions and the release page, else `none`; and the GitHub API address of the repository | `specs/release-check.md` |
| NewerVersionRoute | REST endpoint | `src/server/newer-version-route.ts` | `GET /api/newer-version`: the result of the release check of this server start, never a new check | `specs/newer-version-route.md` |
| useNewerVersion | frontend hook | `src/web/newer-version/newer-version-loader.ts` | Loads the newer version once per page mount, in the background; `null` on none or failure | `specs/newer-version-loader.md` |
| InstalledVersionRoute | REST endpoint | `src/server/installed-version-route.ts` | `GET /api/installed-version`: the installed version given at start, at once, never waiting for the release check | `specs/installed-version-route.md` |
| useInstalledVersion | frontend hook | `src/web/installed-version-loader.ts` | Loads the installed version once per page mount; `null` while loading and on failure | `specs/installed-version-loader.md` |
| NewerVersionNotice | UI component | `src/web/newer-version/NewerVersionNotice.tsx` | Glass box "Update Available" under the top bar at the right: both versions, "View Release" link, "Close Update Notice" | `specs/newer-version-notice.md` |
| ThirdPartyNotices | document | `THIRD-PARTY-NOTICES.md` | Source, version and licence of each third-party font and icon set | `specs/third-party-notices.md` |
