# Module sessions

|-----------|------|------|----------------|------|

| TerminalMirror | backend service | `src/server/sessions/terminal-mirror.ts` | Headless terminal of a session that gives a serialized snapshot | `specs/terminal-mirror.md` |
| StartSessionRoute | REST endpoint | `src/server/sessions/start-session-route.ts` | `POST /api/sessions`: starts a session in an existing folder | `specs/start-session-route.md` |

| DismissSessionRoute | REST endpoint | `src/server/sessions/dismiss-session-route.ts` | `POST /api/sessions/:id/dismiss`: removes an ended hosted session from the list | `specs/dismiss-session-route.md` |
| ResumeEndedSessionRoute | REST endpoint | `src/server/sessions/resume-ended-session-route.ts` | `POST /api/sessions/:id/resume`: resumes an ended hosted session, with the running-elsewhere check, and removes its ended entry | `specs/resume-ended-session-route.md` |
| AttachSessionRoute | REST endpoint (WebSocket) | `src/server/sessions/attach-session-route.ts` | `GET /api/sessions/:id/attach`: snapshot, live output, input and resize | `specs/attach-session-route.md` |
| SessionView | UI component | `src/web/sessions/SessionView.tsx` | Open hosted session: 40 px subbar with "Search", "Interrupt" and "Terminate", xterm.js terminal on a panel that stays dark in both themes, links opened with Ctrl+click and the address tooltip of hyperlinks, terminal search with Ctrl+Shift+F, text zoom with Ctrl+=, Ctrl++, Ctrl+- and Ctrl+0, file drop that pastes the paths in the desktop app, attach again every 2 s after a lost connection, footer with path, figures and the text size controls | `specs/session-view.md` |
| TerminalSearchBox | UI component | `src/web/sessions/TerminalSearchBox.tsx` | Search box at the top right of the terminal panel: field, "N of M" or "No results", previous, next and close, with Enter, Shift+Enter and Esc | `specs/terminal-search-box.md` |
| TerminalFontSizeStore | frontend service | `src/web/sessions/terminal-font-size-store.ts` | One text size for all hosted terminals: 8 to 32 px, default 12 px, larger, smaller and reset, saved in `localStorage` | `specs/terminal-font-size-store.md` |
| TerminalZoomControls | UI component | `src/web/sessions/TerminalZoomControls.tsx` | Footer buttons "Smaller text", default size (shows "<size> px") and "Larger text", disabled at the limits | `specs/terminal-zoom-controls.md` |
| droppedPathsText | frontend function | `src/web/sessions/dropped-paths-text.ts` | Text of a drop: each path followed by one space, quoted in single quotes when it has spaces or shell-special characters | `specs/dropped-paths-text.md` |
| LinkOpener | frontend function | `src/web/sessions/link-opener.ts` | Opens an `http`/`https` address in a new tab with no opener; any other scheme does nothing | `specs/link-opener.md` |
| WebAddressLinks | frontend function | `src/web/sessions/web-address-links.ts` | Link provider of the `http`/`https` addresses in the terminal rows, with wrapped and full-row addresses joined | `specs/web-address-links.md` |
| SessionHeader | UI component | `src/web/sessions/SessionHeader.tsx` | 40 px subbar of the open session: folder name, line chip cut with its full-text tooltip, leading actions, state pill, actions | `specs/session-header.md` |
| SessionFooter | UI component | `src/web/sessions/SessionFooter.tsx` | 40 px footer of the open session: optional lead text, path cut with its tooltip, figures, end items at the right | `specs/session-footer.md` |
| SessionFigures | UI component | `src/web/sessions/SessionFigures.tsx` | Context, total tokens with the four parts in a tooltip, and estimated cost chips of a session summary | `specs/session-figures.md` |
| StopSessionButton | UI component | `src/web/sessions/StopSessionButton.tsx` | Rose "Terminate" button of the open session, with confirmation when working | `specs/stop-session-button.md` |
| HookSettings | configuration | `src/server/sessions/hook-settings.ts`, `src/server/sessions/hook-forwarder.mjs` | Claude Code settings file whose hooks post each event to the server | `specs/hook-settings.md` |
| SessionNameStore | backend service | `src/server/sessions/session-name-store.ts` | Names the user gives to sessions, by session key, saved in a JSON file of the client's data folder | `specs/session-name-store.md` |
| RenameSessionRoute | REST endpoint | `src/server/sessions/rename-session-route.ts` | `PUT /api/sessions/:id/name`: sets or clears the name of a hosted or external session | `specs/rename-session-route.md` |
| SessionStateTracker | backend service | `src/server/sessions/session-state-tracker.ts` | State, label (the name when set), last activity, waiting tool, resumable mark and Claude Code session id of each session, with change listeners that get the cause of each change, and the removal of ended sessions | `specs/session-state-tracker.md` |
| HookEventRoute | REST endpoint | `src/server/sessions/hook-event-route.ts` | `POST /api/sessions/:id/hook-events`: passes a hook event to the tracker | `specs/hook-event-route.md` |
| SessionListRoute | REST endpoint | `src/server/sessions/session-list-route.ts` | `GET /api/sessions`: the hosted and external sessions with their summary | `specs/session-list-route.md` |
| SessionEventsRoute | REST endpoint (WebSocket) | `src/server/sessions/session-events-route.ts` | `GET /api/sessions/events`: pushes each session change to the pages | `specs/session-events-route.md` |
| AttentionMonitor | backend service | `src/server/sessions/attention-monitor.ts` | Events when a hosted or external session enters `needs_input` or ends a turn, or a hosted session ends without a user stop, and the list of the sessions that need input, with the time each started to wait | `specs/attention-monitor.md` |
| runningToolOf | backend function | `src/server/sessions/running-tool.ts` | Open tool calls of a session to the tool of the tool line: last call, first line of its main argument, count of the others | `specs/running-tool.md` |
| RunningToolMonitor | backend service | `src/server/sessions/running-tool-monitor.ts` | Follows the main transcript of each working session, hosted or external, and notifies the running tool, held at least 1 s | `specs/running-tool-monitor.md` |
| modelResponseOf | backend function | `src/server/sessions/model-response.ts` | One transcript line to the model response it records: key, model, token counts with the 5-minute and 1-hour cache write split, sidechain mark | `specs/model-response.md` |
| contextWindowOf | backend function | `src/server/sessions/context-window.ts` | Context window size of a model id: 1,000,000 for extended models, the "[1m]" marker or more than 200,000 used tokens, else 200,000 | `specs/context-window.md` |
| pricingOf | backend function | `src/server/sessions/price-list.ts` | API list prices of a model id in USD per million tokens, with prompt-length tiers, read on 2026-11-06 | `specs/price-list.md` |
| costOf | backend function | `src/server/sessions/response-cost.ts` | Estimated cost of one response at the prices of its model, or unknown | `specs/response-cost.md` |
| contextAfter | backend function | `src/server/sessions/context-occupancy.ts` | Context occupancy (used tokens and window) of a session from the lines of its main transcript, cleared by a compaction | `specs/context-occupancy.md` |
| ResponseLedger | backend service | `src/server/sessions/response-ledger.ts` | Responses of one session, one record per key with its final values and cost, the sums of input, output, cache write and cache read, and the sum of the known costs with the incomplete mark | `specs/response-ledger.md` |
| UsageMonitor | backend service | `src/server/sessions/usage-monitor.ts` | Follows the main transcript and the subagent files of every hosted and external session, in limited chunks, and notifies its context, tokens consumed and estimated cost | `specs/usage-monitor.md` |
| TurnReader | backend service | `src/server/sessions/turn-reader.ts` | Reads the end of a session transcript: Claude's final response of the last turn, and whether the user interrupted it | `specs/turn-reader.md` |
| plainExcerpt | backend function | `src/server/sessions/plain-excerpt.ts` | Markdown response to plain text of at most 100 characters | `specs/plain-excerpt.md` |
| AttentionRoute | REST endpoint (WebSocket) | `src/server/sessions/attention-route.ts` | `GET /api/attention`: the needs-input list on connect and on each change, and each new event | `specs/attention-route.md` |
| groupSessions, orderSessions | frontend function | `src/web/sessions/session-order.ts` | The four list groups in order; inside each, the given order, then latest activity first | `specs/session-order.md` |
| nextSessionOrder | frontend function | `src/web/sessions/next-session-order.ts` | New order of each group from the previous order and the current sessions | `specs/next-session-order.md` |
| SessionOrderStore | frontend service | `src/web/sessions/session-order-store.ts` | Order of the sessions inside each group, kept current, moved by the user and saved in `localStorage` | `specs/session-order-store.md` |
| LiveSessionStore | frontend service | `src/web/sessions/live-session-store.ts` | Session list in the page and its load status, loaded at each connection, kept current by events, reconnected every 2 s after a loss | `specs/live-session-store.md` |
| SessionList | UI component | `src/web/sessions/SessionList.tsx` | Grouped compact session rows with status dots, the context percentage, the estimated cost and the running tool line, the amber needs-input card with "Reply", "Rename" on every entry; a click opens a session, a drag moves it inside its group | `specs/session-list.md` |
| shortTokens, percentOf, usageLevelOf, costText | frontend function | `src/web/sessions/usage-format.ts` | Short form of a token count, context percentage and its level (normal, warning, error), cost text | `specs/usage-format.md` |
| SessionNameEditor | UI component | `src/web/sessions/SessionNameEditor.tsx` | "Session Name" field that edits a session name in place of the entry label: Enter saves, Esc or blur cancels | `specs/session-name-editor.md` |
| EndedEntryActions | UI component | `src/web/sessions/EndedEntryActions.tsx` | "Resume" and "Dismiss" icon buttons of an ended hosted entry, with the running-elsewhere warning and the error under the entry | `specs/ended-entry-actions.md` |
| NeedsInputCounter | UI component | `src/web/sessions/NeedsInputCounter.tsx` | Amber pill "N need input" ("1 needs input") of the list panel, hidden at zero, and the count for the rail badge | `specs/needs-input-counter.md` |
| StateBadge | UI component | `src/web/sessions/StateBadge.tsx` | State of a session as a pulsing dot, a mono name or the tinted pill, in the status colours | `specs/state-badge.md` |

| RelativeTime | UI component | `src/web/sessions/RelativeTime.tsx` | "Just now", "Nm ago", `HH:MM` or date of a last activity, refreshed every 30 s | `specs/relative-time.md` |
| ProgressBar | UI component | `src/web/sessions/ProgressBar.tsx` | Thin emerald indeterminate bar of a working entry | `specs/progress-bar.md` |
