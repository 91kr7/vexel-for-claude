# Module activity

| Component | Type | Path | Responsibility | Spec |
|-----------|------|------|----------------|------|
| startsTurn | backend function | `src/server/activity/turn-rule.ts` | Whether a main transcript line starts a turn: a user message that is not an interrupt marker or a message added by Claude Code | `specs/turn-rule.md` |
| subagentStateOf | backend function | `src/server/activity/subagent-state.ts` | State of a subagent (running, finished, stopped), and the subagent stop notices of the main transcript | `specs/subagent-state.md` |
| workflowSubagentStateOf | backend function | `src/server/activity/workflow-state.ts` | State of a workflow subagent (running, finished, stopped) from its run journal and its launch, and the launch and end of a workflow in a transcript line | `specs/workflow-state.md` |
| TurnModel | backend service | `src/server/activity/turn-model.ts` | Current turn of one session from its transcript lines, subagent metadata and workflow run journals: turn start and number, steps of the main conversation, latest text of each conversation, state, times, model, starting step and its message of each subagent and workflow subagent, message of a call of an earlier turn, workflow launches, time of the last activity, open tool calls | `specs/turn-model.md` |
| liveActivityOf | backend function | `src/server/activity/live-activity.ts` | Live activity of a session: at work, the latest text of the main conversation or of a running subagent (plain, cut at 400 characters), the time of the last activity and what the session waits for | `specs/live-activity.md` |
| waitingForOf | backend function | `src/server/activity/waiting-for.ts` | What a session at work waits for: the first started of its running tools, without the calls that started a running subagent, or Claude's response | `specs/waiting-for.md` |
| ActivityMonitor | backend service | `src/server/activity/activity-monitor.ts` | Follows the main transcript, subagent files, workflow subagent files, run journals and metadata of every hosted and external session, in limited chunks, and notifies its live activity and the changes of its turn tree | `specs/activity-monitor.md` |
| turnTreeOf | backend function | `src/server/activity/turn-tree.ts` | Tree of the subagents that run now, of any turn (groups of level 0 in start order, nested groups, a child of an ended parent in the place of that parent, subagent fields) and the parts that changed between two trees | `specs/turn-tree.md` |
| TurnRoute | REST endpoint | `src/server/activity/turn-route.ts` | WebSocket `GET /api/sessions/:id/turn`: the whole tree, then its changes; `4404` for an unknown id | `specs/turn-route.md` |
| locateSubagentFile | backend function | `src/server/activity/subagent-file-locator.ts` | File of one subagent (workflow subagents included) of a hosted or an external session, from its agent id | `specs/subagent-file-locator.md` |
| SubagentConversationRoute | REST endpoint (WebSocket) | `src/server/activity/subagent-conversation-route.ts` | WebSocket `GET /api/sessions/:id/subagents/:agentId/conversation`: all items of the subagent, then the new ones live; `4404` for an unknown session or agent | `specs/subagent-conversation-route.md` |
| SubagentItemContentRoute | REST endpoint | `src/server/activity/subagent-item-content-route.ts` | `GET /api/sessions/:id/subagents/:agentId/items`: full content of one tool call or tool result of a subagent | `specs/subagent-item-content-route.md` |
| shortDuration | frontend function | `src/web/activity/short-duration.ts` | Short text of a duration: "42 s", "3 min", "1 h 05 min" | `specs/short-duration.md` |
| ElapsedTime | UI component | `src/web/activity/ElapsedTime.tsx` | Time since a moment in the short form, refreshed every second by one shared timer of the page, which `useNow` also gives | `specs/elapsed-time.md` |
| stallText | frontend function | `src/web/activity/stall-text.ts` | Text of the stall signal: "No activity for 8 min · sdd-tester: mvn test running +2" | `specs/stall-text.md` |
| useTurn | frontend hook | `src/web/activity/turn-store.ts` | Tree of the running subagents of the open session from TurnRoute: loading, unavailable or loaded, updates applied and subagents that left dropped, a new socket 2 s after a lost one | `specs/turn-store.md` |
| TurnPanelButton | UI component | `src/web/activity/TurnPanelButton.tsx` | Header icon button "Subagents" (`list-tree`) that opens and closes the Subagents panel, for every session | `specs/turn-panel-button.md` |
| TurnPanel | UI component | `src/web/activity/TurnPanel.tsx` | Right panel "Subagents" of the session content: header "Subagents", the tree of the running subagents, or the conversation of one subagent in its place, kept open when that subagent ends; slides as the git explorer | `specs/turn-panel.md` |
| TurnTreeView | UI component | `src/web/activity/TurnTreeView.tsx` | Running subagents as rows: the groups in start order, nested rows one level further right, a line with ticks joining a group of two or more, "No subagents running.", follows the latest started subagent | `specs/turn-tree-view.md` |
| SubagentCard | UI component | `src/web/activity/SubagentCard.tsx` | Row of one subagent: type chip, state pill, description, model, duration, latest text on two lines, current tool, as the button "Open Conversation: <type>" | `specs/subagent-card.md` |
| SubagentConversation | UI component | `src/web/activity/SubagentConversation.tsx` | Read-only conversation of one subagent in the Subagents panel: bar with "Back", type, description and state (none once the subagent left the list), then the conversation body with user items named "Task"; Esc acts as "Back" | `specs/subagent-conversation.md` |
