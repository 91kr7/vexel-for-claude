# Module desktop

| Component | Type | Path | Responsibility | Spec |
|-----------|------|------|----------------|------|
| DesktopApp | Electron main process | `src/desktop/main.ts` | One-instance frameless window and tray icon: shows the startup page, starts the backend through the launcher, loads the client page, wires the notifications, the tray signal and the needs-input sound requests, answers the read and save of the remote notification settings and the test notification request, sends web links to the system browser, keeps the page zoom keys out of the menu; close hides the window, quit confirms and stops the backend it started; the page's quit request quits with no question | `specs/desktop-app.md` |
| BackendLauncher | backend service | `src/desktop/backend-launcher.ts` | Reuses a backend that answers the health check, or starts the server detached and waits until it is ready or has failed; stops the server it started | `specs/backend-launcher.md` |
| StartupPage | UI page | `src/desktop/startup-page.ts` | Light data URL page with a 38 px drag bar on top holding the window buttons, "Starting the backend…" or "The backend could not start." with the output lines | `specs/startup-page.md` |
| AppIcon | asset | `src/desktop/icons/vexel-for-claude.svg`, `src/desktop/icons/vexel-for-claude.png` | "VX" logo mark icon for the menu entry and the window | `specs/app-icon.md` |
| AttentionIcon | asset | `src/desktop/icons/vexel-for-claude-attention.svg`, `src/desktop/icons/vexel-for-claude-attention.png` | The AppIcon with an amber badge, for the tray while a session needs input | `specs/attention-icon.md` |
| MenuEntry | configuration and command | `src/desktop/menu-entry.ts`, `src/desktop/install-menu-entry.ts` | Desktop Entry "Vexel for Claude" and the install command that writes it into the application menu | `specs/menu-entry.md` |
| TrayIcon | UI component | `src/desktop/tray-icon.ts` | Tray icon, tooltip and menu: normal or attention look by the sessions that need input, one entry per waiting session, then "Open Window" and "Quit" | `specs/tray-icon.md` |
| QuitCheck | backend service | `src/desktop/quit-check.ts` | Counts the busy hosted sessions of a backend the app started and asks "Quit Vexel for Claude?" when there are any | `specs/quit-check.md` |
| AttentionClient | backend service | `src/desktop/attention-client.ts` | WebSocket to `/api/attention` that passes on events and needs-input lists, and connects again every 2 s after a drop | `specs/attention-client.md` |
| NotificationRules | backend service | `src/desktop/notification-rules.ts` | Decides which notification to show, group in 5-second bursts or close, from events, the needs-input list, the window focus and the open session | `specs/notification-rules.md` |
| SoundRule | backend service | `src/desktop/sound-rule.ts` | Decides which attention events play the needs-input sound: a new `needs_input` event when no sound played in the last 5 s | `specs/sound-rule.md` |
| NotificationTexts | backend service | `src/desktop/notification-texts.ts` | English title "<folder> · <label>" and body of each notification, and the grouped title and body | `specs/notification-texts.md` |
| SystemNotifications | backend service | `src/desktop/system-notifications.ts` | Shows, replaces and closes one notification per session over D-Bus `org.freedesktop.Notifications`, and reports clicks and closes | `specs/system-notifications.md` |
| DesktopBridge | Electron preload | `src/desktop/desktop-bridge.cts` | `window.desktopBridge`: the page reports its open session, receives "open this session" and the sound requests, reads the absolute path of a dropped file, closes, minimizes, maximizes or restores the window, asks the app to quit, reads and saves the remote notification settings, and asks for a test notification | `specs/desktop-bridge.md` |
| RemoteSettingsStore | backend service | `src/desktop/remote-settings-store.ts` | Reads and saves the remote switch, the topic URL and the token in a JSON file of mode `0600`; defaults when nothing is saved | `specs/remote-settings-store.md` |
| NtfyPublisher | backend service | `src/desktop/ntfy-publisher.ts` | Posts one message as JSON to the root of an ntfy server, with the token when set, within 10 s; gives "sent" or "failed" with a short reason that never holds the token | `specs/ntfy-publisher.md` |
| WindowActions | backend service | `src/desktop/window-actions.ts` | Closes, minimizes, maximizes or restores the window on requests of its own page, runs the quit flow it is given on the page's quit request, and sends the page the maximized state | `specs/window-actions.md` |
